# Trinity Bus Express frontend

Static HTML, CSS and vanilla JavaScript website for GitHub Pages or local use.

## Included in this build
- Mobile-first responsive layout from 320px to large desktop screens
- 8 long-form route guides
- 20 long-form blog guides
- 53 city GEO destination pages
- 6 country GEO hubs
- Route, destination, country, blog, travel-guide and HTML sitemap hubs
- Organization, LocalBusiness, WebSite, SearchAction, WebPage, CollectionPage, Article, FAQPage, BreadcrumbList and BusTrip structured data where relevant
- XML sitemap and image sitemap
- Keyword research map with more than 5,000 long-tail phrase combinations
- WhatsApp-first booking and call actions

## Important production setup
The project uses `https://example.com/trinity-bus-express/` as the canonical base because no final public domain was supplied. Replace this base URL in HTML, sitemap.xml, image-sitemap.xml and robots.txt with the real GitHub Pages custom domain before launch.

Do not add a physical office address, email address, awards, partnerships, live seat claims or certifications until the real business information is verified.
