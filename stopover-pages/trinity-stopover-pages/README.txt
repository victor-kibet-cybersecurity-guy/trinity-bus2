TRINITY BUS EXPRESS STOPOVER LANDING PAGES

Included pages:
- nairobi-to-eldoret-bus.html
- nairobi-to-malaba-bus.html
- eldoret-to-kampala-bus.html
- malaba-to-kampala-bus.html
- nairobi-to-jinja-bus.html
- kampala-to-gulu-bus.html
- kampala-to-kigali-bus.html
- kigali-to-goma-bus.html

Also included:
- assets/stopover-pages.css
- assets/stopover-pages.js

Recommended integration:
1. Copy the HTML files into the root of trinity-bus2.
2. Copy the assets folder into the existing assets directory.
3. Add links to these pages from routes.html and relevant main-route pages.
4. Add these URLs to sitemap.xml.
5. Link main routes to stopovers, for example:
   Nairobi to Kampala -> Nairobi to Eldoret -> Nairobi to Malaba -> Eldoret to Kampala -> Malaba to Kampala -> Nairobi to Jinja
6. Replace any unverified schedules, terminals, fares or operating details with confirmed information.
